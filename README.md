# ml-notes

My working notebook for the backend → AI/ML transition (Oct 2026 → Nov 2027). Concepts in my own words, the maths I'm closing gaps on, vocabulary, and solved SQL / DSA problems. Everything here is written to be re-read, not just stored.

## Layout

| Folder | What goes here |
| --- | --- |
| `logs/` | Daily log — one short entry per study day (what I covered, what clicked, what didn't) |
| `notes/` | Per-topic notes: linear algebra, StatQuest, MLCC, probability, stats |
| `maths-gaps.md` | Running list of maths gaps found while doing exercises, with status |
| `vocab/` | ML vocabulary (60-term test, Anki exports) |
| `sql/` | StrataScratch / SQL problems, one file per problem, with timing |
| `dsa/` | NeetCode solutions, one file per problem, with timing |

## How I use it

- Commit something every study day — the daily log entry counts.
- Notes are intuition-first: the reason an idea exists, an example, an analogy, then the formula.
- A topic gets revisited across the 400 days; I append rather than overwrite, dating each pass.
